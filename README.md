# 15-Puzzle – State Space Exploration

A university Artificial Intelligence project focused on modeling the 15-Puzzle problem and exploring its state space using Python.

## Overview

This project implements the basic structure of the 15-Puzzle, including board representation, valid moves, and state exploration.

It uses **Breadth-First Search (BFS)** to explore reachable states and stores the discovered states in an SQLite database.

## Features

- 4×4 puzzle board representation
- Valid move generation
- State normalization
- Breadth-First Search (BFS) exploration
- SQLite database for storing explored states
- Introduction to the Manhattan Distance heuristic

## Technologies

- Python
- Jupyter Notebook
- SQLite

## How to Run

1. Clone or download this repository.
2. Open `puzzle.ipynb` in Jupyter Notebook or VS Code.
3. Run the cells sequentially.
